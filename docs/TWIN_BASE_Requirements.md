# TWIN BASE 公式Webサイト制作指示書

## 1. プロジェクト概要

TWIN ASSISTの関連事業である、ドッグラン＆カフェ「TWIN BASE」の公式Webサイトを制作してください。

**Webデザイン、UI/UX、フロントエンド実装に精通したトップクラスのWebデザイナー兼エンジニアとして制作してください。**

一般的なAI生成サイトのような、テンプレート的・画一的なデザインは避け、細部までこだわったオリジナルサイトを目指します。

### 基本情報

- 施設名：TWIN BASE
- 業態：DOG RUN & CAFE
- 運営：TWIN ASSIST
- 所在地：大阪府大阪市西成区北津守1丁目2-1
- サイト形式：1ページ完結型（LP形式）
- 対応端末：PC・スマートフォン・タブレット
- 言語：日本語
- 主な目的：認知拡大、来店促進、Instagramフォロー、公式LINE登録、イベント集客

### 参考サイト

https://grass-grass.jp/

https://pawpark.jp/

参考サイトの親しみやすさや写真の見せ方、余白、曲線の使い方を研究してください。

ただし、デザインをそのまま模倣せず、TWIN BASE独自の世界観を構築してください。

### 文字色

### カラーのルール

- ミルクホワイトをサイト全体のベースに使用
- 淡いパステルカラーをセクションごとに取り入れる
- 原色や高彩度のカラーは使用しない
- 黒・濃紺・濃いブラウンを基本的に使用しない
- 背景に柔らかな色の変化を持たせる
- ボタンも淡い色で設計し、文字とのコントラストを確保
- 文字の可読性やアクセシビリティは維持する

画面全体が単調な白一色にならないよう、柔らかい色面や曲線を使ってリズムを生み出してください。

## 4. フォント設計

AIが生成するWebサイトにありがちな、無機質で汎用的なフォントの使用を避けてください。

### 日本語フォント

見出し：Zen Maru Gothic

本文：M PLUS Rounded 1c

アクセント：Kiwi Maru（必要な箇所のみ）

Google Fontsを使用して構いません。

### フォントの表現

- 丸みのあるゴシック体を中心に使用
- 見出しは少し大きめで柔らかい印象
- 文字間や行間を丁寧に調整
- 太さを使い分けてメリハリを作る
- 英語の小見出しは控えめなアクセントにする
- 不自然な英語の多用を避ける
- スマートフォンでの読みやすさを重視する

文字だけで可愛らしさを表現するのではなく、余白やレイアウトと組み合わせて洗練させてください。

## 5. ロゴの取り扱い

提供するTWIN BASEのロゴ画像を使用してください。

### 必須加工

1. ロゴ周囲の円形背景を削除
2. 犬・柵・芝生・文字などのロゴ本体だけを切り抜く
3. PNG形式の透過背景で保存
4. ロゴの色、文字、形は変更しない
5. ロゴ周囲に不自然な余白を残さない
6. 切り抜きの境界を滑らかに仕上げる

ロゴは白背景やミルクホワイト背景に自然になじむよう配置してください。

ロゴの青や茶色など、既存のブランドカラーは変更しません。ただし、Webサイト側の装飾色には濃い色を多用しないでください。

## 6. デザイン・レイアウトの重要ルール

### 有機的な曲線を積極的に使用

本サイトの重要な特徴は、有機的な曲線を使用したデザインです。

以下の表現を取り入れてください。

- 波のようにゆるやかなセクション境界
- アーチ型の写真フレーム
- 非対称な丸みを持つ画像
- 雲のような柔らかな装飾
- 曲線を使った背景の切り替え
- 丸く膨らんだボタン
- 余白を活かした非対称レイアウト
- 小さな犬の足跡や手描き風の装飾

CSS border-radius、SVG、clip-pathなどを活用してください。

### 避けるべきデザイン

- 同じ大きさの四角いカードを3つ並べるだけの構成
- 全セクションが同じレイアウト
- 画面中央にすべての文字を配置する単調な構成
- 過剰なグラデーション
- 強すぎるドロップシャドウ
- 不自然に浮かぶカード
- AI生成サイト特有の巨大な英語見出し
- 画一的なアイコンの多用
- 不必要な装飾
- 既視感のあるSaaS系テンプレート

重要なのは、曲線を大量に使うことではありません。

**セクションごとに変化を持たせ、統一されたデザインルールの中で自然なリズムを生み出すことです。**

## 12. 制作フロー

以下の順番で作業してください。

1. 提供されたロゴと施設写真を確認
2. ロゴの円形背景を取り除き透過PNGを作成
3. 参考サイトの特徴を分析
4. 配色・フォント・デザインルールを定義
5. PC・スマホのレイアウトを設計
6. ファーストビューを丁寧に制作
7. 各セクションを実装
8. レスポンシブ対応
9. アニメーションを実装
10. 表示・操作・デザインを検証

### 検証項目

- PCとスマホでレイアウトが崩れていないか
- 丸みや曲線が自然に表現されているか
- 写真の重要部分が見切れていないか
- AIテンプレートのような単調な構成になっていないか
- フォントが指定どおり表示されているか
- 全体の余白・文字サイズ・配色に統一感があるか
- ボタンやリンクが正常に機能するか
- 未確定情報を事実として記載していないか

可能であればブラウザでPC・スマホ両方のスクリーンショットを撮影し、視覚的な問題を修正してください。

## 13. 最重要指示

今回のサイトでは、以下の5つを最優先してください。

**① AIっぽくない、洗練されたオリジナルデザイン**

同じカードやグリッドを繰り返すだけのテンプレート的なデザインは禁止します。

**② ミルクホワイトを中心とした淡いカラー**

濃いカラーを使わず、柔らかく明るい印象にしてください。

**③ 有機的な曲線と丸みのあるデザイン**

全体に自然な曲線を取り入れ、心地よい視覚的リズムを生み出してください。

**④ 丸ゴシックを使った温かみのあるタイポグラフィ**

犬系サイトらしい親しみやすさと、大人向けカフェの洗練を両立してください。

**⑤ 実際に来店したくなるサイト**

サイトを閲覧した人が、愛犬と一緒に過ごす時間を自然に想像できるデザインにしてください。

目標は、単に可愛いサイトではありません。

**「愛犬と過ごす、もうひとつのリビング。」というコンセプトが、スクロールするだけで伝わるブランドサイトです。**

制作物は完成したWebサイトのソースコード、加工済みロゴ画像、必要なアセットを含めて提出してください。
