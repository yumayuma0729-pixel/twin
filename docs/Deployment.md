# 無料プレビュー公開と移行

## 現在の状態

静的トップページをNetlifyに公開できる構成です。無料プランの提供条件・上限は契約画面で確認してください。PHP・MySQLのCMSはNetlifyの静的配信では動作しません。CMS実装時にはPHP対応サーバーへ移すか、別バックエンドを用意する必要があります。

## 最初の公開

1. https://app.netlify.com/drop にアクセスしてログインします。
2. `previews/twin-assist-site.zip` を解凍します。
3. `index.html`、`style.css`、`app.js` が入ったフォルダーをアップロードします。
4. Netlifyが発行したHTTPSのサイトURLを確認します。

手動アップロードは自動更新されません。変更後に公開フォルダーを再アップロードします。秘密情報や管理画面をこの公開ファイルに含めないでください。

## GitHub連携による自動反映

ソースをGitHubのtwinリポジトリへ保存した後、Netlifyで既存プロジェクトをGitHubへ連携します。公開対象ブランチを指定し、公開ディレクトリを `public`、ビルドコマンドを空欄に設定します。ルートの `netlify.toml` にも公開ディレクトリを指定しています。アカウントでの連携許可はユーザーが行います。以降は対象ブランチへのpushで再公開されます。ローカルでの編集だけでは外部サイトに反映されません。

## 有料サーバーへの移行

現在の静的ページは `public` の内容を新サーバーの公開領域へ配置できます。CMS実装後は、PHP実行環境・DB・画像・非公開設定・メール配送・定期処理の移行も必要です。独自ドメインを使う場合は、新環境でHTTPSと動作確認を終えてからDNSを切り替えます。Netlifyのサブドメインは他社サーバーへそのまま持ち運べません。独自ドメイン自体の取得費用は別途かかります。

今回、外部サービスへのアップロードやURL発行はまだ行っていません。
