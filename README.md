# Twin Assist

トップページの制作プレビューです。PHP CMS実装前の静的UIであり、公開済みサイトではありません。

## 起動

Node.js 24で動作確認済み。外部パッケージのインストールは不要です。

```sh
cd /workspace/twin
npm run dev
```

既定ポートは3000。変更時は `PORT=3001 npm run dev` を使用します。プロセスは新しい環境で再起動してください。

## 現在の範囲

レスポンシブTOP、PC固定サイド、スマホ固定CTA、メニュー、用途選択、検索の空状態、相談窓口未登録の案内を実装。ヒーローと案内欄には生成したライフスタイル写真を使用しています。実店舗・実車・実在の顧客の写真ではなく、在庫画像としては使用していません。実素材提供後に差し替えます。実在庫のDB連携・実LINE/電話接続・送信フォーム・CMSは未実装です。静的な下層ページは追加済みです。現在のページはnoindexにしています。

## カーストーリーとステートメント

「お客様のカーストーリー」はスマホ2枚、768px以上では3枚の掲載準備中カードを表示します。実記事は未登録で、架空のお客様の体験談は掲載していません。「もっと見る」は `/story/` へ遷移します。会社・事業紹介の次に、想いを受け継ぐブランドステートメントを追加しています。

検証サーバーを別ポートで動かす場合は `PREVIEW_URL=http://127.0.0.1:3001 node scripts/check-preview.cjs` を使用できます。

## トータルサポート・FAQ・コラム

購入・売却・車検・整備をヒーローとサービス欄に集約し、旧注文販売／買取の独立セクションを削除しました。ステートメント直後にFAQ6件、続いてコラム3本と本文・一覧ページを追加しています。車種案内はブルーの軽自動車・白い商用バン・白いトラックの生成イメージを使用し、実在庫や実所在地の写真と誤認しない注記を付けています。車種カードは対応する用途ボタンを選択します。

コラムは一般的な説明で、特定車両の価格・整備結果・査定額を保証するものではありません。公開前に事業者による内容確認を行ってください。現時点では全ページnoindexを維持しているため、検索流入を狙う本公開時に、正規ドメイン・canonical・サイトマップ・公開承認と合わせてindex設定を切り替える必要があります。SEO順位向上や即時インデックスを保証するものではありません。

## 詳細ページ・追従CTA・明朗会計

`/stock/`（URLに検索条件を保持、0件表示）、`/buy/`（販売・注文販売）、`/sell/`、`/inspection/`、`/maintenance/`、`/company/`、`/business/`、`/contact/` を追加しました。全ページでLINE・電話の追従CTAを表示します。正式URL・番号は未確定なので準備中ダイアログを表示し、発信・外部送信はしません。電話受付時間13:00〜22:00はユーザー指定で、店舗営業時間とは別です。

車種案内は生成イラスト、サポートはCSSのタイヤモチーフへ変更。価格案内は他社ロゴ・金額を流用せず、総額の仕組みを示すオリジナルのプライスボードです。会社情報、許認可、実在庫、実サービス条件の最終確認とCMSの実装は今後必要です。

Chromiumでトップ8幅、12ページを320/390/768/1440pxで検証。LINE・電話の準備中ダイアログ、ページ内・ページ間リンク、在庫の用途・キーワード・ソート条件保持とリセットを確認しました。

## 在庫カテゴリの整理

在庫検索と車種案内を「軽自動車」「商用車（軽バン・トラック）」「乗用車」に統一。URLパラメータはkei/commercial/passengerです。過去のvan/truckパラメータは商用車に読み替え、他の検索条件は保持します。車種案内は白背景・輪郭と陰影のある生成カタログイラストを使用し、軽自動車はブルー、商用車はバンとトラック、乗用車は赤いハッチバックで表現しています。実在庫の写真ではありません。

## 検索ピクトグラムとオレンジ背景

大きな車種カードのイラストは維持。検索ボタン部分のみ、車種ごとに独立した透過生成イラストをcontain表示し、共通CSSによる画像上書きと車体の切れを解消しました。明朗会計・コラム・詳細ページの主要なベージュ背景をオレンジ（#ff6600）へ変更し、補助面はオレンジの淡色で統一。ブランドステートメントのみ元のベージュを維持しています。色は参考イメージに基づく選定で、他社の正式ブランドカラーを検証したものではありません。

## 青色への変更

ユーザーの最新指定により、オレンジ配色を青（#1754a5）へ変更しました。青背景上の見出し・本文・補助見出し・リンク・手順番号は白、白いカードとプライスボード内は濃色を維持し、補助背景も淡い青に統一しています。ステートメントのベージュは維持しています。

## Twin Assistの強み・ハニカム

トップのタイヤ型サポート欄を、濃紺・青・シルバーのハニカム構成へ変更しました。添付ロゴから背景除去した表示用PNGを中央に配置し、周囲の購入・売却・車検・整備から `/strengths/` の該当セクションへ遷移します。強みページには4つの相談内容、明朗会計の考え方、既存詳細ページへのリンクを掲載しています。添付ロゴは画像処理した表示用素材のため、正式な透過PNG/SVGが届いた場合は置き換えてください。

トップ8幅の検証に加え、320/390/768/1440pxで中央ロゴの読み込み、4つの強みリンク、詳細セクションへの移動、横はみ出しとJavaScriptエラーがないことを確認しました。

## ロードアシスタンス追加

ユーザー確認により、ロードアシスタンスを5つ目の強みに追加。トップと強みページのハニカム、専用 `/road-assistance/` ページ、ナビ・会社概要・事業内容・整備案内を更新しました。対応地域・時間・内容・費用・出動可否は未確認として明示し、24時間対応や無料対応等は表示していません。サイトの連絡先自体は引き続き未登録です。

## 強みのスクロール表現

トップは同じ大きさの六角形を中央ロゴの周囲へ放射状に配置し、面の色と装飾を抑えました。強みページは白いグリッド、曲線、大きな番号と英語見出しで01〜05を縦に読み進める構成へ変更。自然スクロールに合わせて目次の現在位置と番号を更新し、一度だけ軽い出現効果を付けています。スクロールの強制移動や固定は行いません。JavaScript無効でも全文を表示し、prefers-reduced-motion時は出現効果を省略します。

320/390/768/1440pxで5つのハニカムリンクとスクロールの01〜05連動、JavaScript無効時の本文表示、動きの軽減設定を確認しました。

## 見出しとコンパクトな価格案内

トップのサポート欄は「クルマの事なら／全部ツインアシストで完結」→ハニカム→強みページCTAの縦順へ変更。説明文を一行に整理し、明朗会計ボードのナビ・ETCなどの個別用品欄を削除しました。価格の仕組み・任意オプションの区別・適用条件は残しています。390pxで価格セクションは約478px、PC1440pxで約314pxの高さを確認しました。

## ハニカムと背景の再設計

ユーザーの最新指定により、強い青の主要面をチャコール・オフホワイト・シルバーに再構成。`public/refinement.css` で現行の最終配色と図形を管理しています。ハニカムは統一寸法の格子で中心ロゴ＋5サービスを配置し、空いた角にONE PARTNERの署名を置く構成です。見出し→図→強みCTAの順序、強みページのスクロール目次、ステートメントのベージュは維持しています。
