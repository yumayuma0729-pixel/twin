# Twin Assist

黒・チャコール・シルバーと写真を主役にした公式サイトの制作プレビューです。公開中のCloudflare側は静的UIです。別途 `cms/` にPHP＋MySQLの独自CMS初期版を実装しました。静的サイトと通常のCMS開発環境はnoindexです。

## 起動

Node.js 24で動作確認済み。実行用の外部依存はありません。

```sh
cd /workspace/twin
npm run dev
```

既定ポートは3000。`PORT=3001 npm run dev` で変更できます。新しい環境ではプロセスを再起動してください。

## 現在のページ

- TOP、在庫一覧、販売・注文販売、買取・下取り
- 車検、整備・修理、ロードアシスタンス
- 強み（01〜06の自然スクロールと目次連動）、会社概要、事業内容、窓口
- お客様のカーストーリー一覧（実記事未登録）、コラム一覧と3本の本文

在庫のカテゴリは軽自動車・商用車（軽バン/トラック）・乗用車。用途/キーワード/並び順をURLに保持し、旧van/truckはcommercialへ読み替えます。実在庫は未登録です。ユーザー指定により各カテゴリ2台・計6台の制作確認用デモを掲載し、画像・価格・仕様が実在庫ではない旨を一覧・各カード・詳細に明記しています。

## デザイン

- `style.css`：基本の構造とレスポンシブ表示
- `refinement.css`：現在の黒・シルバーパレット、6サービスのハニカム、写真と手書き風コピー

直前の大きな英字・ブルーグレーの案と、未公開の太い道路波線は撤去しました。6つのハニカムは上2/左右2/下2で、中央はTWIN文字も囲み枠もないロゴマーク単体。洗車・コーティングは準備中と明記しています。

写真・車種イラストは生成素材で、実店舗・スタッフ・顧客・実在庫の素材ではありません。ページ上にも注記しています。正式素材は提供後に差し替えます。ロゴは添付を元に背景除去・文字除去を施した表示用素材で、正式な透過PNG/SVGがあれば差し替えてください。

ヒーローの手書き風英語にはCaveat（SIL OFL）をローカル配信。ライセンスは `public/fonts/Caveat-LICENSE.txt` に同梱しています。

## 選択済みカテゴリからサンプル詳細へ

TOPの車種ボタン/カードは、そのカテゴリの条件が入った在庫一覧へ直接遷移します。再入力フォームは閉じた「条件を変更する」に移動。6台のデモ用仕様はpublic/data/demo-inventory.jsonに記録し、一覧・詳細は静的HTMLで表示しています。実在庫・CMSへの接続ではありません。

`/stock/demo-kei-01/` 等に全6台の詳細ページを作成。サンプル価格内訳・仕様・同カテゴリの別サンプル・戻るリンクを用意しています。注文販売の専用セクションは `/buy/#order` で、一覧/詳細/TOPの案内から直接移動できます。サンプル車の購入予約はできません。

`PREVIEW_URL=http://127.0.0.1:3001 node scripts/check-inventory.cjs` で、カテゴリ別2台表示、6詳細URL、デモ/noindex、価格フィルタ/ソート/空結果、旧カテゴリの読替え、入力文字列の安全な表示、変更とリセット、注文販売への遷移を検証できます。320/390/768/1440pxで一連の導線、320〜1440pxの複数幅で一覧/詳細/注文販売の横はみ出しを確認済みです。

## 車両詳細の画像拡大・同価格帯とお問い合わせフォーム

車両画像はボタンで拡大ダイアログを表示（閉じる・Escape対応）。同価格帯はサンプル総額±30万円から価格差順で最大3台を選び、自車を除外しています。予約/相談リンクは `/contact/?type=visit&vehicle=demo-...` のように車両サンプルと種別だけを引き継ぎます。予約は希望のリクエストであり、確定表示はありません。

`contact.css` と `contact.js` は入力→確認→修正の制作プレビューです。来店希望日は過去日を不可とし、種別に応じた日時欄、電話返信時の電話番号必須化、文字数、同意を検証。確認表示はtextContentで構築し、自由入力をHTML・URL・ログ・ローカルストレージへ出しません。実送信・サーバー保存・通知は未接続で、最終送信ボタンを無効化しています。JavaScript無効時は入力も無効です。

`/privacy/` は現在のプレビューでの取扱いと、本番前に事業者情報・利用目的・保存期間・窓口等を確定すべきことを説明する暫定ページです。正式な個人情報保護方針やサーバー側の検証/スパム対策/受付保存/メール到達・失敗処理を終えるまで本番フォームとして案内しないでください。

参考に指定された k-nagon.co.jp の2URLはこの環境のネットワークで403となり、ページ構成自体は未確認です。今回は独自の一般的な車両詳細・予約相談UIとして実装しています。

`PREVIEW_URL=http://127.0.0.1:3001 node scripts/check-vehicle-contact.cjs` で、全6車両の画像と±30万円の関連車、車両引継ぎ、入力検証・安全な確認表示・編集保持、実POSTなし、JS無効時の無送信を確認できます。Chromiumで320/390/768/1440pxの詳細・フォーム・プライバシーページを確認済みです。


## 独自CMS初期版（PHP＋MySQL）

`./scripts/start-cms.sh` でDockerのPHP＋MariaDBを起動し、DB初期化・ログイン画面のHTTP確認まで行います。本番のPHPは8.2以上、開発検証は8.3です。`cms/dev/.env`、`cms/config/local.php`、アップロード画像・DB・バックアップはGitに含めません。既定パスワードや公開セットアップ画面はありません。

- 在庫：車両情報、総額の整合性、販売状態、装備、写真の選択・順序、下書きと公開の分離、公開停止、ごみ箱・復元。
- 記事：カーストーリー、お知らせ、コラム。簡易Markdown、画像、関連記事、SEO項目。
- 問い合わせ：入力確認→明示送信→DB保存、重複防止、通知キュー、担当・対応状況・メモ。完了データは管理者が確認のうえ完全削除可能。
- 認証：個別アカウント、管理者/編集者/問い合わせ担当、CSRF、試行制限、セッション期限、パスワード変更時の既存セッション失効。
- SEO：公開・検索対象指定・非サンプルのCMS詳細のみサイトマップ自動生成。開発は全体停止。本番でのインデックス登録は検索エンジンの判断。

**公開URLの `/admin/` は読み取り専用のUIプレビューです。実際に保存するCMSはCloudflareの静的配信では動きません。** PHP環境の `/admin/` は認証された管理画面になります。PHPアプリ・設定は `public/` の外です。

`python3 scripts/package-xserver.py` で秘密値・実データなしの設置用ZIPを `dist/` に生成。`python3 scripts/backup-cms-dev.py` はローカルDB・非公開画像のバックアップです。別DBへの復元と画像一致を確認しました。本番サーバーのバックアップ・cron・メール・Basic認証等は契約後に確認します。

[CMS設置手順](docs/CMS_Deployment.md) / [CMS操作マニュアル](docs/CMS_Manual.md)

統合検証： `node tests/cms-integration.cjs`（localhostの検証環境とGit外のテストアカウント情報が必要。本番では実行しない）。通常開発とは別の `app-test` profileで受付・検索対象を有効にした検証を行います。予約公開、MFA、CSV出力、WYSIWYG、一般ページ/会社設定のGUI編集は初期版の対象外です。

### 装備・タグ・SEO/AIOの拡張

装備は6分類65項目の三状態（未確認/あり/なし）です。共通カタログは `public/data/cms-catalog.json`。CMSは手動タグと、タイトルを優先した本文等の自動タグを重複排除して24件まで表示。地域は「大正区の方向け」で所在地・対応範囲の断定ではありません。関連タグから記事一覧の絞り込みと関連記事の補完を行い、タグ絞り込みはnoindexです。

要点・確認ポイント・FAQ・参考資料・内容確認日を編集でき、表示内容と一致するArticle/BreadcrumbList/FAQPageを生成します。AI引用やインデックス・順位を保証する機能ではありません。開発中のnoindex・サイトマップ対象制御は維持します。既存ページのタグ等は `scripts/refresh-static-topics.py` で更新。本番前は `--base-url` を正式URLへ合わせて再生成してください。

追加検証：`tests/cms-discovery.php`（PHP環境）、`tests/cms-discovery-ui.cjs`（localhostテスト環境・非公開のテストアカウントが必要）。
