# Twin Assist

トップページの制作プレビューです。PHP CMS実装前の静的UIであり、公開済みサイトではありません。

## 起動

Node.js 24で動作確認済み。外部パッケージのインストールは不要です。

```sh
cd /workspace/twin
npm run dev
```

既定ポートは3000。変更時は `PORT=3001 npm run dev` を使用します。プロセスは新しい環境で再起動してください。

## 現在の範囲

レスポンシブTOP、PC固定サイド、スマホ固定CTA、メニュー、用途選択、検索の空状態、相談窓口未登録の案内を実装。ヒーローと案内欄には生成したライフスタイル写真を使用しています。実店舗・実車・実在の顧客の写真ではなく、在庫画像としては使用していません。実素材提供後に差し替えます。実在庫のDB連携・実LINE/電話接続・送信フォーム・CMSは未実装です。静的な下層ページは追加済みです。現在のページはnoindexにしています。

## 検証

Chromiumで320/375/390/430/768/1280/1440/1920pxの横はみ出し、メニュー開閉、用途選択、検索空状態、相談ダイアログ、Escape操作、JavaScriptエラーを確認しました。Safari/Firefoxは未確認です。

`node scripts/check-preview.cjs` は環境にPlaywrightと `/usr/bin/chromium` がある場合の検証用です。起動済みのポート3000を使用します。

- [要件定義](docs/Twin_Assist_Requirements.md)

## カーストーリーとステートメント

「お客様のカーストーリー」はスマホ2枚、768px以上では3枚の掲載準備中カードを表示します。実記事は未登録で、架空のお客様の体験談は掲載していません。「もっと見る」は `/story/` へ遷移します。会社・事業紹介の次に、想いを受け継ぐブランドステートメントを追加しています。

検証サーバーを別ポートで動かす場合は `PREVIEW_URL=http://127.0.0.1:3001 node scripts/check-preview.cjs` を使用できます。

## トータルサポート・FAQ・コラム

購入・売却・車検・整備をヒーローとサービス欄に集約し、旧注文販売／買取の独立セクションを削除しました。ステートメント直後にFAQ6件、続いてコラム3本と本文・一覧ページを追加しています。車種案内はブルーの軽自動車・白い商用バン・白いトラックの生成イメージを使用し、実在庫や実所在地の写真と誤認しない注記を付けています。車種カードは対応する用途ボタンを選択します。

コラムは一般的な説明で、特定車両の価格・整備結果・査定額を保証するものではありません。公開前に事業者による内容確認を行ってください。現時点では全ページnoindexを維持しているため、検索流入を狙う本公開時に、正規ドメイン・canonical・サイトマップ・公開承認と合わせてindex設定を切り替える必要があります。SEO順位向上や即時インデックスを保証するものではありません。

## 詳細ページ・追従CTA・明朗会計

`/stock/`（URLに検索条件を保持、0件表示）、`/buy/`（販売・注文販売）、`/sell/`、`/inspection/`、`/maintenance/`、`/company/`、`/business/`、`/contact/` を追加しました。全ページでLINE・電話の追従CTAを表示します。正式URL・番号は未確定なので準備中ダイアログを表示し、発信・外部送信はしません。電話受付時間13:00〜22:00はユーザー指定で、店舗営業時間とは別です。

車種案内は生成イラスト、サポートはCSSのタイヤモチーフへ変更。価格案内は他社ロゴ・金額を流用せず、総額の仕組みを示すオリジナルのプライスボードです。会社情報、許認可、実在庫、実サービス条件の最終確認とCMSの実装は今後必要です。

Chromiumでトップ8幅、12ページを320/390/768/1440pxで検証。LINE・電話の準備中ダイアログ、ページ内・ページ間リンク、在庫の用途・キーワード・ソート条件保持とリセットを確認しました。
