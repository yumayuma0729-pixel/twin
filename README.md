# Twin Assist

黒・チャコール・シルバーと写真を主役にした公式サイトの制作プレビューです。現時点は静的UIで、PHP・MySQLのCMSは未実装です。全ページnoindexを維持しています。

## 起動

Node.js 24で動作確認済み。実行用の外部依存はありません。

```sh
cd /workspace/twin
npm run dev
```

既定ポートは3000。`PORT=3001 npm run dev` で変更できます。新しい環境ではプロセスを再起動してください。

## 現在のページ

- TOP、在庫一覧、販売・注文販売、買取・下取り
- 車検、整備・修理、ロードアシスタンス
- 強み（01〜06の自然スクロールと目次連動）、会社概要、事業内容、窓口
- お客様のカーストーリー一覧（実記事未登録）、コラム一覧と3本の本文

在庫のカテゴリは軽自動車・商用車（軽バン/トラック）・乗用車。用途/キーワード/並び順をURLに保持し、旧van/truckはcommercialへ読み替えます。公開在庫は0台で、架空の車両や価格は表示しません。

## デザイン

- `style.css`：基本の構造とレスポンシブ表示
- `refinement.css`：現在の黒・シルバーパレット、6サービスのハニカム、写真と手書き風コピー
- `detail-pages.css`：トップと共通の写真ヒーロー・日本語見出し・モノトーンの詳細ページ

直前の大きな英字・ブルーグレーの案と、未公開の太い道路波線は撤去しました。6つのハニカムは上2/左右2/下2で、中央はTWIN文字も囲み枠もないロゴマーク単体。洗車・コーティングは準備中と明記しています。

写真・車種イラストは生成素材で、実店舗・スタッフ・顧客・実在庫の素材ではありません。ページ上にも注記しています。正式素材は提供後に差し替えます。ロゴは添付を元に背景除去・文字除去を施した表示用素材で、正式な透過PNG/SVGがあれば差し替えてください。

ヒーローの手書き風英語にはCaveat（SIL OFL）をローカル配信。ライセンスは `public/fonts/Caveat-LICENSE.txt` に同梱しています。

## 確認

Chromiumでトップの320/375/390/430/768/1280/1440/1920px、メニュー、検索空状態、準備中ダイアログを確認しています。主要9詳細ページも同じ8幅で横はみ出し・見出し・画像を確認。13画面×4幅でLINE/電話案内・ローカルリンク・在庫条件保持とリセット、強み01〜06の連動を確認済みです。Safari/Firefoxは未確認です。

既存のPlaywrightと`/usr/bin/chromium`がある環境では、起動後に以下を実行できます。

```sh
node scripts/check-preview.cjs
# 別ポートの場合
PREVIEW_URL=http://127.0.0.1:3001 node scripts/check-preview.cjs
```

`previews/` に現在のPC・スマホ画像と、public全体をまとめたZIPを保存しています。ZIPの存在はチャットでのダウンロード可否を保証しません。
